# Express README notes

Source: [Express README](https://raw.githubusercontent.com/expressjs/express/master/Readme.md)

## Structure observed

- Title + badges
- Short one-line project description
- Code of conduct note
- Table of contents
- Installation
- Features
- Docs & Community
- Quick Start
- Philosophy
- Examples
- Contributing
  - Security Issues
  - Running Tests
- Project team members / governance
- License

## What to copy for a project README

- Put a clear title and short value proposition at the top
- Include a quick start section with install/run commands
- Add features and examples early
- Add docs/community/support links
- Add contributing and license sections at the end
