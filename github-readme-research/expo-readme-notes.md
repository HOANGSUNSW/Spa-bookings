# Expo README notes

Source: [Expo README](https://raw.githubusercontent.com/expo/expo/main/README.md)

## Structure observed

- Title / banner / badges
- Introduction
- Table of contents
- Documentation section
- Project layout section
- Badges section
- Contributing section
- FAQ / support section
- Team section
- License section

## What to copy for a project README

- Document project layout clearly for large monorepos
- Add a table of contents
- Include official documentation and support links
- Explain repository structure and where to edit code
- Add FAQ, team, and license sections if the project is public
